# 💻 Lista de Exercícios — Front-end

Repositório criado para organizar e apresentar os exercícios desenvolvidos durante os estudos de **Programação Front-end**.

O projeto foi organizado por temas, com o objetivo de facilitar a visualização das atividades, acompanhar a evolução dos conhecimentos e demonstrar a utilização de **HTML, CSS e JavaScript**.

## 📚 Organização do projeto

Os exercícios estão separados em quatro temas:

* **01 — Semântica HTML**
* **02 — Formulários Web e Mobile**
* **03 — Responsividade**
* **04 — Interfaces Interativas com JavaScript**

---

# 📁 01 — Semântica HTML

Exercícios relacionados à estruturação correta de páginas utilizando elementos semânticos do HTML.

### Exercícios

* [ ] Criar uma página HTML utilizando estrutura semântica.
* [ ] Utilizar elementos como `header`, `nav`, `main`, `section`, `article`, `aside` e `footer`.
* [ ] Converter um layout feito com `div` para uma estrutura utilizando elementos semânticos.
* [ ] Utilizar corretamente `figure` e `figcaption` para imagens e suas legendas.
* [ ] Estruturar um artigo de blog utilizando `article` e seus respectivos subtópicos dentro de `section`.
* [ ] Criar um menu de navegação utilizando `nav` e listas `ul` e `li`.
* [ ] Aplicar estilos CSS ao menu de navegação.

### 🎯 Objetivo

Praticar a utilização da **semântica do HTML**, criando páginas mais organizadas, acessíveis e seguindo boas práticas de desenvolvimento web.

---

# 📁 02 — Formulários Web e Mobile

Exercícios voltados para criação e estilização de formulários para páginas web e dispositivos móveis.

### Exercícios

* [ ] Criar um formulário de cadastro.
* [ ] Adicionar campos de nome, e-mail e senha.
* [ ] Criar um botão de envio.
* [ ] Adicionar validação utilizando `required`.
* [ ] Utilizar `pattern` para validação de campos.
* [ ] Criar um formulário de login responsivo.
* [ ] Utilizar Flexbox ou Grid para organizar o formulário.
* [ ] Criar um formulário utilizando `fieldset` e `legend`.
* [ ] Organizar informações pessoais e informações de endereço.
* [ ] Desenvolver um formulário de pesquisa.
* [ ] Criar e estilizar o botão de envio.

### 🎯 Objetivo

Aprender a criar formulários funcionais, organizados e responsivos, utilizando recursos nativos do HTML5 e técnicas de CSS.

---

# 📁 03 — Responsividade

Exercícios relacionados à adaptação das interfaces para diferentes tamanhos de tela e dispositivos.

### Exercícios

* [ ] Criar um layout responsivo utilizando `@media queries`.
* [ ] Adaptar a página para diferentes tamanhos de tela.
* [ ] Criar um menu de navegação que se transforme em menu hamburguer em telas menores.
* [ ] Utilizar unidades relativas como `em`, `rem` e `%`.
* [ ] Substituir valores fixos em pixels quando necessário.
* [ ] Adicionar a meta tag `viewport` ao documento HTML.
* [ ] Testar a diferença de comportamento com e sem a meta `viewport`.
* [ ] Criar um carrossel de imagens responsivo utilizando apenas CSS.

### 🎯 Objetivo

Desenvolver interfaces que funcionem corretamente em **computadores, tablets e celulares**, utilizando técnicas de responsividade e boas práticas de CSS.

---

# 📁 04 — Interfaces Interativas com JavaScript

Exercícios destinados à criação de funcionalidades interativas utilizando JavaScript.

### Exercícios

* [ ] Criar um botão que muda de cor ao passar o mouse utilizando JavaScript.
* [ ] Desenvolver um contador de cliques.
* [ ] Exibir a quantidade de cliques em tempo real na página.
* [ ] Criar um modal de aviso.
* [ ] Fazer o modal aparecer ao clicar em um botão.
* [ ] Fazer o modal desaparecer ao clicar fora dele.
* [ ] Criar uma galeria de imagens.
* [ ] Permitir que as imagens sejam ampliadas ao serem clicadas.
* [ ] Desenvolver um sistema de abas (tabs).
* [ ] Exibir diferentes conteúdos de acordo com a aba selecionada.

### 🎯 Objetivo

Praticar **JavaScript e manipulação do DOM**, desenvolvendo páginas mais interativas e dinâmicas.
